# 🚗 Car Market Trends Analysis with CarDekho Data

## 📌 Project Overview

This project analyzes the provided **CarDekho used-car dataset** using Python and data analytics techniques to identify patterns and trends in the pre-owned vehicle market.

The analysis explores vehicle attributes such as **selling price, present price, manufacturing year, kilometres driven, fuel type, seller type, transmission, ownership, and car name** to understand the characteristics and pricing patterns within the dataset.

---

## 🎯 Project Objective

To analyze the provided CarDekho car dataset using Python and data analytics techniques to identify car market trends and patterns based on factors such as **selling price, car year, fuel type, kilometres driven, seller type, and transmission**.

---

## 📂 Dataset

**Dataset:** `car_data.csv`

The dataset contains **301 vehicle records** with **9 attributes**:

- Car Name
- Manufacturing Year
- Selling Price
- Present Price
- Kilometres Driven
- Fuel Type
- Seller Type
- Transmission
- Owner
